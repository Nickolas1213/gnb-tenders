# Тендеры ГНБ — GNB Line

Сервис сам ищет актуальные закупки на ГНБ, проколы и бестраншейную прокладку труб
по всей России (44-ФЗ и 223-ФЗ) и для каждой считает возможную прибыль по вашим расценкам.

## Как пользоваться

1. Откройте страницу сервиса (адрес вида `https://<ваш-логин>.github.io/gnb-tenders/`).
2. Нажмите **«⚙ Мои расценки»** и впишите свои цифры: стоимость метра для бригады,
   трубы, выезда, котлованов, налог. Всё сохраняется в этом браузере.
3. В списке у каждой закупки видно: начальную цену, цену после торгов, прибыль, маржу
   и «до скольки процентов можно снижать цену», чтобы не уйти в минус.
4. Если метраж не нашёлся в тексте закупки, он **оценивается** по цене (помечено жёлтым).
   Откройте смету из блока «Подробный расчёт и документы» и впишите точный метраж — расчёт обновится.
5. Фильтры: регион, расстояние от Оренбурга, закон, цена, «только прибыльные».

Список обновляется автоматически каждые 2 часа.

## Откуда данные

| Источник | Что даёт | Ограничения |
|---|---|---|
| **ГосПлан API** (gosplan.info) — используется | Закупки 44-ФЗ и 223-ФЗ из ЕИС, обновляются в течение дня | Бесплатно: 10 запросов в минуту. Платный ключ: 3 000 ₽/мес, быстрее и стабильнее |
| ЕИС zakupki.gov.ru напрямую | Первоисточник | Не открывается из-за рубежа (в т.ч. через зарубежный VPN). FTP закрыт с 2025 года; новый сервис отдачи данных требует токен ЕИС через Госуслуги |
| Коммерческие площадки (B2B-Center, Фабрикант, ТЭК-Торг и др.) | Закупки частных компаний | Бесплатного открытого API нет. Подключаются через платные агрегаторы (Контур.Закупки, Тендерплан, Seldon и т.п.) |

Сайты не обходятся и капчи не решаются: используется только открытый API.

## Платный ключ ГосПлан (по желанию)

Если бесплатного лимита перестанет хватать: получите ключ в Telegram-боте ГосПлан (7 дней бесплатно),
затем в репозитории на GitHub: **Settings → Secrets and variables → Actions → New repository secret**,
имя `GOSPLAN_API_KEY`, значение — ваш ключ.

## Файлы

- `index.html` — страница со списком и расчётом.
- `fetch.ps1` — сборщик закупок (ключевые слова — в начале файла).
- `data/tenders.json` — найденные закупки, обновляется автоматически.
- `.github/workflows/update.yml` — расписание обновления на GitHub.

Запуск сборщика на своём компьютере (необязательно):

```
powershell -ExecutionPolicy Bypass -File fetch.ps1
```
